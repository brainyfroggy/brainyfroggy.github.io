NIfTI ROI Editor

Inspect a 3D image, mark voxels in linked views, and export a region of interest as a NIfTI mask. The sample below is synthetic, so you can try the workflow immediately.

Open full-screen editor ↗Read the guide ↓

Try the editor

The synthetic anatomy and activation maps load automatically. Choose Paint, select voxels in any view, and export a mask. You can also open your own 3D NIfTI files.

For more room, open the editor in a new tab. The sample is a generated phantom, not human imaging data.

Using the editor

Quick start

  1. Start with the synthetic sample, or choose Open Background for a 3D NIfTI-1 image.
  2. Optionally choose Add Overlay for a second map. Adjust its color, opacity, and displayed value range.
  3. Paint or erase on axial, coronal, or sagittal slices. Fill Slice selects eligible voxels in the current plane; Sphere selects a 3D neighborhood. Use the mouse wheel or slice arrows to move through the volume.
  4. Use Undo if needed, then choose Export ROI to download a labeled .nii.gz mask in the background image's grid.

What the tool does

Linked viewsThree orthogonal slices share a crosshair and ROI labels.
Overlay alignmentWhen geometry differs, the overlay is mapped to the background grid using its NIfTI affine and nearest-neighbor sampling.
Local editingFiles opened from your device are read in the browser; this page has no file-upload service.

Format and limits

This browser prototype supports single-volume, 3D NIfTI-1 .nii and .nii.gz files up to 20 million voxels. NIfTI-2 and time series are rejected with a clear message. With an overlay loaded, paint and fill operate on nonzero voxels inside the displayed value range. The exported mask uses integer region labels and the background image's spatial header.

Large volumes can be slow or exceed a device's browser memory. Undo history is limited by a memory budget. Nearest-neighbor overlay sampling preserves labels but is not intended as a general-purpose interpolation method for continuous images. Verify exported masks in your analysis software before using them in research; this is not a clinical tool.

Data and provenance

The built-in sample volumes and preview were generated specifically for this demo. The optional MNI152 Template button downloads a public template from NiiVue. The editor's gzip library is served with the site. Your local files stay in browser memory and are cleared when the page closes or reloads.
